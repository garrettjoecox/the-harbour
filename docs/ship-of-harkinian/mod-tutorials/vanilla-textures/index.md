# Using Vanilla Textures

When making a custom model, either to save space or to support texture packs, you might want to reference textures that already exist in the game. This guide assumes you already have the Ocarina of Time decompilation set up and know the basics of how to make a model mod for Ship of Harkinian.

:::note
This guide is specifically for using textures from Ocarina of Time, but if you would rather use textures from Majora's Mask, proceed to [this section of the guide](#majoras-mask-textures) instead.
:::

## Step 1 - Setup

The first thing to do is to get the textures you want from your decompilation of Ocarina of Time. Copy each texture you want to use into a separate folder (preferably the texture folder for your project).

:::tip
If you're using textures from a model you imported into Blender, you can instead unpack that texture from Blender into your current directory if you would prefer that.
:::


## Step 2 - Renaming

Starting with the first texture you want to use, search the [Decomp vs SoH Texture Sheet](https://docs.google.com/spreadsheets/d/127TlFH2p7lgPxhMWCXA5gT2jdv7KtnmcObpHG-WYCgc/edit?usp=sharing) for the texture's name (it is recommended you copy the name of the texture in your folder, move over to the spreadsheet, hit ctrl-F, and paste into the search bar). You should find a matching SoH name for your texture. Copy that name, move back to your texture folder, and rename your texture to that new name. For example, if I had "hilite_1.rgba16", I would rename it to its SoH equivalent of "gHilite1Tex" by finding it in the spreadsheet.


## Step 3 - Material Settings

Now go back to Blender and set your desired material to use your newly renamed texture (Sources Tab in your material properties). Before moving on, ensure that the texture format is correct for that texture; it should match the format specified by the original decomp texture name (ex: "hilite_1.rgba16" should have the RGBA 16-Bit format). If you are not sure which texture format the decomp extension is referring to, please consult the table below.

| Decomp Extension | Corresponding Texture Format |
| ---------------- | ---------------------------- |
| rgba32 | RGBA 32-Bit |
| rgba16 | RGBA 16-Bit |
| ci8 | Color Index 8-Bit |
| ci4 | Color Index 4-Bit |
| ia16 | Intensity Alpha 16-Bit |
| ia8 | Intensity Alpha 8-Bit |
| ia4 | Intensity Alpha 4-Bit |
| i8 | Intensity 8-Bit |
| i4 | Intensity 4-Bit |

If your texture is color-indexed (either Color Index 8-Bit or Color Index 4-Bit), move back to the [spreadsheet](https://docs.google.com/spreadsheets/d/127TlFH2p7lgPxhMWCXA5gT2jdv7KtnmcObpHG-WYCgc/edit?usp=sharing) and copy the name in the "Corresponding TLUT" column for your texture, move back into Blender, and paste the name into the "TLUT Name" box (Sources Tab in your material properties) for your material. Then move back to the spreadsheet and copy the number in the "Color Count" column into the "Color Count" box back in Blender.

Finally, check the box labeled "Is Vanilla Texture?". This will prevent the texture from actually exporting.


## Step 4 - Repeating

Repeat steps 1-3 for each vanilla texture you want to use. Once complete, you have successfully set up vanilla textures for your custom model!


## Majora's Mask Textures

Another option you might want to take is to use textures from Majora's Mask in your Ship of Harkinian mod. The main reason you would want to do this is to make your mod compatible with texture mods for 2Ship2Harkinian. To use MM textures in your mod as opposed to OoT, most of the process is the exact same, just with some minor adjustments:

Begin by following Step 1 as written, but instead of grabbing the textures from your decompilation of Ocarina of Time, use your decompilation of Majora's Mask.

Next, follow Step 2 using the ["mm" sheet in the Decomp vs Ship Textures spreadsheet](https://docs.google.com/spreadsheets/d/127TlFH2p7lgPxhMWCXA5gT2jdv7KtnmcObpHG-WYCgc/edit?usp=sharing)

Then, follow Step 3 but leave the "Is Vanilla Texture?" box unchecked, since this time you actually do want to export your textures since they obviously don't exist in OoT by default.

:::warning
Exporting a color-indexed texture will change the way that it is indexed, as well as the palette itself. To avoid compatibility issues with other mods using that texture/palette it may be best to instead copy the exact textures and palettes you need from an mm.o2r generated by 2Ship.
Technically you could do this for all of your MM textures, but it only really makes a difference for color-indexed textures
:::

Finally, repeat Steps 1 through 3 with the given amendments until you have all of your textures set up.
